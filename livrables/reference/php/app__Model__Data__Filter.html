Filter

Description

MiniShop — constructeur déclaratif de conditions (helper de StoreInterface). Les Repository décrivent leurs filtres avec ces helpers plutôt qu'en écrivant des tableaux à la main : l'intention reste lisible et la spécification sérialisable. JsonStore l'évalue en PHP ; SqlStore la traduit actuellement en clauses SQL préparées pour les opérations génériques. Exemple : $store->select('produit', [ 'where' => [ Filter::eq('visible', 1), Filter::like('nom', '%clavier%'), Filter::between('prix_ttc', 20, 100), ], 'order' => [Filter::sort('prix_ttc', 'desc')], 'limit' => 12, ]);
