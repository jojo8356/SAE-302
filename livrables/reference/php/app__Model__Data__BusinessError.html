BusinessError

Description

MiniShop — erreur métier de la couche de gestion des données. Levée par les « procédures » (Repository) et les « déclencheurs » (Triggers) du moteur — équivalent exact du SIGNAL SQLSTATE '45000' SET MESSAGE_TEXT = '<CODE>' des procédures et déclencheurs SQL (sql/02_minishop_procedures.sql et sql/03_minishop_triggers.sql). Le code (ex. EMAIL_DEJA_UTILISE) est TOUJOURS un identifiant SNAKE_UPPER identique à celui du SQL : les vues et les tests n'ont donc pas besoin de connaître la couche de stockage, quel que soit le pilote actif.
