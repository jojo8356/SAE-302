ParametreRepository

Description

MiniShop — paramètres métier (portage de fn_param + sp_compute_shipping). Les règles chiffrées (frais de port, franchise, TVA par défaut) sont des DONNÉES (table « parametre »), pas des constantes recopiées dans le code : c'est ce qui permet de les faire évoluer sans toucher une ligne de PHP (RB-15, ENF-14).
