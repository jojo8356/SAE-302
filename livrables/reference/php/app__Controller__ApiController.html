ApiController

Description

MiniShop — API interne du panier (EF-CLI-03, §4.5.3 de la DA). Contrepartie serveur du panier sans rechargement. Trois principes : 1. le serveur reste la source unique des prix, du stock et des totaux (EF-GEN-01) : le JSON renvoyé contient les valeurs AFFICHABLES ; 2. toute écriture exige le jeton CSRF de la session (SEC-05), même en « fetch » — le jeton est envoyé dans le corps du formulaire ; 3. les erreurs métier sont traduites en messages humains (EF-GEN-03) et jamais en trace technique. Sans JavaScript, les vues continuent d'utiliser les routes HTML (`POST /panier/ajouter`) : ces routes ne sont qu'une amélioration (ENF-07).
