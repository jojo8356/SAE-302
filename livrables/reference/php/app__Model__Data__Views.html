Views

Description

MiniShop — les 3 vues du schéma (sql/01) portées en opérations JSON. v_etat_stock : produit + état dérivé (RUPTURE / TRES_BAS / DISPONIBLE) v_catalogue : produits visibles + catégorie + état (RB-19) v_commandes_client : commandes + client + nombre de lignes Ces opérations fournissent l'équivalent applicatif des vues SQL au pilote JSON. Les règles utiles (état de stock, visibilité et agrégats) restent alignées sur les définitions de sql/01_minishop_schema.sql. Techniquement, pour le pilote JSON : jointures par table de hachage (index pk du store), zéro SQL — uniquement des opérations de tableaux natifs.
