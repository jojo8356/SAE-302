StorageDriver

Description

MiniShop — énumération du pilote de gestion des données. Le pilote concret est choisi par cette énumération (clé « storage_driver » de la configuration). Le mode SQL est le parcours applicatif principal ; JSON reste disponible explicitement pour les tests portables, les démonstrations sans serveur et les installations isolées. - StorageDriver::SQL → App\Model\Data\SqlStore : MySQL/MariaDB via PDO, procédures, transactions et déclencheurs définis dans sql/01→04. - StorageDriver::JSON → App\Model\Data\JsonStore : tables sous forme de fichiers dans data/minishop ; aucune procédure SQL n'est simulée. Les deux pilotes partagent StoreInterface. Les capacités SQL spécialisées (procédures, fonctions stockées, verrouillage de lignes) sont exposées par des interfaces optionnelles, sans imposer une fausse API SQL au pilote JSON.
