ClientAccountGatewayFactory

Description

Fabrique la stratégie d'accès au compte selon les capacités du pilote. Le test porte sur une interface de capacité plutôt que sur SqlStore : un autre pilote SQL peut réutiliser la stratégie sans modifier le repository.
