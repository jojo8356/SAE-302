DbConnexion

Description

MiniShop — ouverture d'une connexion PDO vers MySQL / MariaDB. Point d'entrée UNIQUE : `SqlStore` (pilote applicatif) et `DbInstaller` (création de la base) passent tous les deux par ici, ce qui supprime le DSN dupliqué qui vivait dans chaque classe. Le point délicat est l'authentification de `root` sous Debian/Ubuntu : MariaDB et MySQL y créent `root@localhost` avec le greffon `unix_socket`, qui **n'accepte pas** de connexion TCP. PHP, lui, se connecte en TCP (`127.0.0.1:3306`), et le serveur répond alors : SQLSTATE[HY000] [1698] Access denied for user 'root'@'localhost' `ouvrir()` traite ce cas précis : si le code d'erreur est 1698 (ou 1045 sur un compte `root` sans mot de passe) et qu'une socket Unix locale existe, la connexion est **réessayée par la socket** — sans rien changer au `.env`. Le répertoire de socket peut aussi être imposé explicitement : DB_SOCKET=/run/mysqld/mysqld.sock C'est le comportement attendu d'un outil de développement : le cas le plus fréquent (poste Debian fraîchement installé) fonctionne sans création de compte applicatif, et `DB_SOCKET` reste la porte de sortie explicite.
