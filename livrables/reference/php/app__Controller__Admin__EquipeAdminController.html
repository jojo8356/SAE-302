EquipeAdminController

Description

MiniShop — gestion des comptes administrateurs (EF-ADM-10, RB-12/13). Réservé au rôle SUPER ; l'administrateur ne gère JAMAIS les comptes clients (RB-13 : le back-office ne crée pas de compte client).

Méthodes publiques (3)

public function index(): void

Affiche la liste des comptes administrateurs (accès réservé au rôle SUPER).

public function creer(): void

Crée un compte administrateur (GESTIONNAIRE ou SUPER) avec hachage bcrypt.

public function basculer(string $id): void

Activer / bloquer un compte admin (jamais de suppression : piste conservée).
