App\Config · app/Config/Env.php

Env

Description

MiniShop — lecture du fichier `.env` (configuration locale). La configuration de l'application vient de trois sources, dans cet ordre de priorité (la dernière gagne) : 1. valeurs par défaut du code (pilote SQL, 127.0.0.1:3306, base minishop) ; 2. `.env` à la racine — fichier LOCAL, jamais commité (`.env.example` est le modèle versionné) ; 3. variables d'environnement réelles du processus (`DB_USER=… ./run.sh`), pratiques en CI, en conteneur et pour un test ponctuel. Le format accepté est volontairement minimal et strict : # commentaire CLE=valeur export CLE="valeur avec espaces" # préfixe `export` toléré CLE='sans interprétation' Aucune expansion de variable, aucune exécution : une ligne non reconnue est ignorée (le fichier reste un simple fichier de données). Les clés sont validées (`[A-Za-z_][A-Za-z0-9_]*`) pour qu'une faute de frappe ne puisse pas polluer l'environnement. Emplacement : `<racine>/.env`, surchargeable par `MINISHOP_ENV_FILE` (utilisé par les tests pour ne jamais toucher au fichier du développeur).
