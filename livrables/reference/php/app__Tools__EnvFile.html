EnvFile

Description

MiniShop — écriture maîtrisée du fichier `.env` (outil de développement). Utilisé par `scripts/db_init.php --switch` et `run.sh --db` pour basculer l'application sur MySQL sans demander au développeur d'éditer un fichier à la main. Le fichier est modifié **ligne à ligne** : les commentaires, l'ordre et les autres clés sont conservés ; une clé absente est ajoutée à la fin. Le fichier cible suit App\Config\Env (donc `MINISHOP_ENV_FILE` en test) et n'est jamais versionné (`.gitignore`).
