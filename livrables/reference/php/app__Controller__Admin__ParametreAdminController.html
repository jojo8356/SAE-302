ParametreAdminController

Description

MiniShop — paramètres commerciaux du back-office (EF-ADM-11). Objet : rendre pilotables SANS déploiement les valeurs qui engagent l'affichage légal du prix — frais de port standard, franchise de port offert, TVA par défaut, durée de conservation des comptes. Ces valeurs étaient déjà des données (`parametre`) mais n'étaient modifiables par aucun écran : c'est l'écart corrigé ici (audit `09` §G). Sécurité : route gardée `admin` (RB-13), CSRF obligatoire, valeur numérique validée côté serveur, écriture journalisée par le moteur (EF-GEN-04) — l'auteur est posé par setActor().
