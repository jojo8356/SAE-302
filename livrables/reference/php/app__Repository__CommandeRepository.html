CommandeRepository

Description

MiniShop — commandes & lignes (portage de sp_create_order, sp_add_order_line, sp_create_order_from_basket, sp_confirm_order, sp_update_order_status, sp_cancel_order, sp_revenue_report). L'ordre des opérations de sp_add_order_line est critique et conservé : 1) contrôle RB-05 (quantité > 0) AVANT toute écriture ; 2) verrou « commande » (statut modifiable : BROUILLON/EN_PREPARATION) ; 3) lecture produit + disponibilité agrégée (stock − déjà réservé) ; 4) INSERT de la ligne (le déclencheur fige le prix RB-06) ; 5) décrément du stock par le déclencheur (RB-18) ; 6) recalcul du montant = Σ lignes + port (RB-15) — le port est recalculé à chaque ligne tant que la commande est BROUILLON (la franchise ne doit pas dépendre de l'ordre d'ajout), puis figé à la validation (RB-20). Toute écriture multi-tables est transactionnelle (ENF-16) : un refus ne laisse JAMAIS de données incohérentes (rollback automatique).
