DbInstaller

Description

MiniShop — installation locale de la base MySQL/MariaDB. Regroupe en une seule classe ce qu'un développeur doit faire à la main : créer la base si elle manque, y charger `sql/01 → 04` (schéma, 18 procédures, 16 déclencheurs, jeu de démonstration), puis **vérifier** que les objets attendus existent réellement. Utilisé par `scripts/db_init.php` et `scripts/load_db.php` (qui reste l'enveloppe historique). La configuration vient de `Database::config()` — donc du fichier `.env` (modèle `.env.example`) : DB_HOST="127.0.0.1" DB_PORT="3306" DB_NAME="minishop" DB_USER="minishop" DB_PASSWORD="…" STORAGE_DRIVER="sql" Aucune valeur n'est concaténée dans le SQL (SEC-01) ; le nom de la base est validé par une liste blanche (`[A-Za-z0-9_]+`) et n'est jamais utilisé comme paramètre lié (MySQL refuse les marqueurs sur les identifiants).
