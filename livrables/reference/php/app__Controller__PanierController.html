PanierController

Description

MiniShop — panier (UC-06, EF-CLI-03/04/06, EF-VIS-09, RB-18/19). Le panier « hors session » est consultable sans compte, mais la commande exige une connexion (contrôleur Commande). Aucun prix ni stock n'est lu dans le navigateur : le serveur est la source unique (EF-GEN-01).
