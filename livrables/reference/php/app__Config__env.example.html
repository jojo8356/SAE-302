env.example

Description

MiniShop — ancien modèle de configuration PHP. ⚠️ Déprécié : la configuration vit désormais dans `.env` à la racine (modèle versionné `.env.example`, lu par App\Config\Env). Les deux formats restent acceptés, `.env` étant prioritaire ; ce fichier n'est conservé que pour les dépôts déjà configurés de cette façon. Ordre de lecture (le dernier gagne) : valeurs par défaut du code → ce fichier (copié vers env.php) → `.env` → variables d'environnement. Hors dépôt : app/Config/env.php est ignoré par .gitignore (règle §14.1). Sans configuration explicite, l'application sélectionne le pilote SQL. Pour le mode secondaire sans serveur, choisir explicitement 'json'.
