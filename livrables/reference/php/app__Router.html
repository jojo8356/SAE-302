Router

Description

MiniShop — routeur à liste blanche (§9.3, D4-L8-01). AUCUNE route dynamique : chaque URL exécutable est déclarée ici, avec sa méthode HTTP et sa garde d'accès ('public' | 'client' | 'admin' | 'super', RB-13). Toute URL inconnue répond 404 — il n'existe pas de « catch-all » qui exposerait une action par accident.
