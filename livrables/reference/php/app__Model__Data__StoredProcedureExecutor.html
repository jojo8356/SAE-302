StoredProcedureExecutor

Description

Capacité optionnelle d'un pilote à exécuter une procédure stockée. Elle est séparée de StoreInterface : le pilote JSON n'a pas à simuler une API SQL qu'il ne peut pas implémenter. Les repositories dépendent de ce contrat, jamais de la classe concrète SqlStore.
